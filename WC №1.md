Мета роботи: 
1. Ознайомлення з системою контролю версій Git, її призначенням, основними поняттями, діями та командами. 
2. Набуття практичних навичок роботи з GitHub.

### Git - це розподілена система контролю версій (Version Control System), яку використовують для керування змінами у файлах проєкту.

Основні завдання Git:
- Зберігати історію всіх змін у проєкті.
- Дозволяти кільком розробникам працювати одночасно.
- Створювати окремі гілки для нових функцій.
- Легко повертатися до будь-якої попередньої версії.
- Працювати локально і синхронізувати зміни з віддаленим репозиторієм (GitHub, GitLab).

### Комміт (commit) у Git - це збереження стану проєкту в певний момент часу. 
#### Кожен коміт - це частина ланцюжка
- Проєкт виглядає як ланцюжок комітів. Кожен новий коміт посилається на попередній. Завдяки цьому можна побачити, як проєкт змінювався з часом.
