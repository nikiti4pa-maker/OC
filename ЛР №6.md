#### Словник базових термінів
- **Archive** — файл, який об’єднує кілька файлів і каталогів в один
- **Compression** — зменшення розміру файлу за допомогою алгоритмів
- **Lossless compression** — оригінальний файл можна повністю відновити
- **Lossy compression** — частина даних безповоротно видаляється
- **Tar** Tape Archive — програма для створення архівів
- **Gzip**  Утиліта стиснення на основі алгоритму DEFLATE
- **Bzip2** Утиліта стиснення на основі алгоритму Burrows-Wheeler
- **Xz** Сучасна утиліта стиснення на основі алгоритму LZMA2
- **Pipe** — перенаправлення виводу однієї команди на ввід іншої
- **Redirect** Перенаправлення потоків вводу/виводу
- **Stdout** Стандартний потік виводу (номер 1)
- **Stderr** Стандартний потік помилок (номер 2)
- **Stdin** Стандартний потік вводу (номер 0)
- **Filter** — команда, яка обробляє дані, що надходять через канал
- **Verbose** Детальний вивід інформації про виконання команди
- **Extract** (розпакувати) вміст архіву
- **Recursive**  — обхід усіх підкаталогів
### Відповіді на завдання попередньої підготовки
#### 5.1. Призначення команд tar, xz, zip, bzip2, gzip
##### **tar**
Призначення: створення, перегляд і розпакування архівів.  
Основні параметри:  
- `-c` — створити архів  
- `-x` — розпакувати  
- `-t` — переглянути вміст  
- `-v` — детальний вивід  
- `-f` — вказати ім’я файлу  
- `-z` — стиснути/розпакувати gzip  
- `-j` — стиснути/розпакувати bzip2  
- `-J` — стиснути/розпакувати xz  

Встановлення: `sudo apt install tar`.

##### **gzip**  
- Призначення: стиснення/розпакування окремих файлів алгоритмом DEFLATE.  
- Основні параметри: `-d` (розпакувати), `-k` (залишити оригінал), `-9` (максимальне стиснення), `-1` (швидке).  
- Встановлення: `sudo apt install gzip`.

##### **bzip2**  
- Призначення: стиснення файлів алгоритмом Burrows-Wheeler (краще стиснення, але повільніше).  
- Основні параметри: `-d` (розпакувати), `-k` (залишити оригінал), `-9` (максимальне).  
- Встановлення: `sudo apt install bzip2`.

##### **xz**  
- Призначення: сучасне стиснення алгоритмом LZMA2 (найкраще стиснення серед класичних утиліт).  
- Основні параметри: `-d` (розпакувати), `-k` (залишити оригінал), `-9` / `-e` (максимальне).  
- Встановлення: `sudo apt install xz-utils`.

##### **zip**  
- Призначення: створення архівів у форматі ZIP (поширений у Windows).  
- Основні параметри: `-r` (рекурсивно), `-9` (максимальне стиснення).  
- Встановлення: **sudo apt install zip unzip**.
#### 5.2. Три приклади архівування та стиснення
1. Створення gzip-архіву каталогу:
- tar -czvf backup.tar.gz /home/user/documents
2. Створення bzip2-архіву:
- tar -cjvf backup.tar.bz2 /etc
3. Створення xz-архіву:
- tar -cJvf backup.tar.xz /var/log
#### 5.3. Призначення команд cat, less, more, head, tail
#####  cat — вивід вмісту файлу (або кількох файлів) на екран.
- Параметри: -n (нумерація рядків).
- Встановлення: входить до coreutils.
#####  less — посторінковий перегляд великих файлів (можна гортати вгору-вниз).
- Параметри: /текст (пошук), q (вихід).
- Встановлення: sudo apt install less.
#####  more — простий посторінковий перегляд (тільки вперед).
- Встановлення: sudo apt install more.
#####  head — вивід перших рядків файлу (за замовчуванням 10).
- Параметри: -n 20 (перші 20 рядків).
- Встановлення: coreutils.
##### tail — вивід останніх рядків файлу.
- Параметри: -n 20, -f (стежити за змінами у реальному часі).
- Встановлення: coreutils.
#### 5.4. Принципи роботи з каналами, потоками та фільтрами
##### У Bash існують три стандартні потоки:
0 — stdin (ввід)
1 — stdout (вивід)
2 — stderr (помилки)
##### Перенаправлення дозволяє змінювати, куди йдуть ці потоки:
- .> — перезаписати файл
- .>> — додати в кінець файлу
- 2> — перенаправити помилки
- &> — перенаправити і вивід, і помилки
##### Канал (|) з’єднує stdout однієї команди з stdin іншої.
Фільтри — це команди, які читають дані зі stdin, обробляють їх і виводять у stdout (наприклад, grep, sort, wc, cut).
#### 5.5. Призначення команди grep
##### grep — пошук рядків у файлах або потоці за заданим шаблоном (регулярним виразом).
##### Основні параметри:
- -i — ігнорувати регістр
- -r / -R — рекурсивний пошук
- -n — показувати номери рядків
- -v — інвертувати пошук (рядки без збігу)
- -c — лише кількість збігів
##### Приклад: grep -i "error" /var/log/syslog

#### Виконання дій з tar
1. Створити звичайний tar-архів:
`tar -cvf archive.tar file1 file2 dir/`
2. Створити архів з кількох файлів і каталогів:
`tar -cvf multi.tar /etc/hosts /var/log/syslog Documents/`
3. Переглянути вміст:
`tar -tvf archive.tar`
4. Розпакувати:
`tar -xvf archive.tar`
5. Створити архів зі стисненням bzip2:
`tar -cjvf archive.tar.bz2 dir/`
6. Розпакувати bzip2-архів:
`tar -xjvf archive.tar.bz2`
7. Створити архів зі стисненням gzip:
`tar -czvf archive.tar.gz dir/`
8. Розпакувати gzip-архів:
`tar -xzvf archive.tar.gz`
#### Перенаправлення потоків
| Команда              | Що виконує                                         |
| -------------------- | -------------------------------------------------- |
| cmd 1> file          | Перенаправляє stdout у файл (перезаписує)          |
| cmd > file           | Те саме, що і попереднє (1 за замовчуванням)       |
| cmd 2> file          | Перенаправляє stderr у файл                        |
| cmd >> file          | Додає stdout у кінець файлу                        |
| cmd &> file          | Перенаправляє і stdout, і stderr у файл            |
| cmd > file 2>&1      | stdout і stderr у один файл                        |
| cmd >> file 2>&1     | Додає stdout і stderr у кінець файлу               |
| cmd 2>&1 > /dev/null | Спочатку stderr → stdout, потім stdout → /dev/null |
| cmd 2> /dev/null     | Приховує повідомлення про помилки                  |
| cmd1 \| cmd2         | Канал: вивід cmd1 → ввід cmd2                      |
| cmd1 2>&1 \| cmd2    | Канал з об’єднаними stdout і stderr                |
#### Пояснення прикладів перенаправлення
| Команда                                    | Що виконує                            | Тип перенаправлення               |
| ------------------------------------------ | ------------------------------------- | --------------------------------- |
| echo "It is a new story." > story          | Записує текст у файл story            | stdout → файл                     |
| date > date.txt                            | Записує поточну дату у файл           | stdout → файл                     |
| cat file1 file2 file3 > bigfile            | Об’єднує три файли в один             | stdout → файл                     |
| ls -l >> directory                         | Додає список файлів у кінець          | stdout → додавання                |
| sort < file1_unsorted > file2_sorted       | Сортує файл                           | stdin ← файл, stdout → файл       |
| find -name '*.txt' > file.txt 2> /dev/null | Шукає .txt, помилки ігнорує           | stdout → файл, stderr → /dev/null |
| cat file1_unsorted \| sort > file2_sorted  | Сортування через канал                | pipe + stdout → файл              |
| cat myfile \| grep student \| wc -l        | Підрахунок рядків зі словом "student" | два канали (фільтри)              |
### Відповіді на контрольні запитання
#### 1.

**Архівування** — це процес об’єднання кількох файлів і каталогів в один файл (архів) зі збереженням структури каталогів, прав доступу, власників та інших метаданих. Основна мета — зручність зберігання, передачі та резервування даних. Класичний інструмент — tar.

**Стискання** — це процес зменшення розміру файлу (або архіву) за допомогою спеціальних алгоритмів. Розрізняють:
- **lossless** (без втрат) — оригінальні дані можна повністю відновити (gzip, bzip2, xz);
- **lossy** (з втратами) — частина інформації безповоротно видаляється (MP3, JPEG).
#### 2.
- 7z / p7zip — високий ступінь стиснення, підтримка багатьох форматів.
- rar / unrar — популярний формат RAR.
- zstd — сучасний швидкий алгоритм з хорошим стисненням.
- lz4 — дуже швидке стиснення.
#### 3. 
##### Порівняння алгоритмів
- gzip (DEFLATE) — найшвидший, середнє стиснення.
- bzip2 (Burrows-Wheeler) — краще стиснення, повільніший.
- xz (LZMA2) — найкраще стиснення, найповільніший.
- Найшвидший — gzip, найефективніший за розміром — xz.
#### 4. 

 Android: файлові менеджери (Solid Explorer, RAR), додатки ZArchiver, 7Zipper.
 
 iOS: Files, Documents by Readdle, iZip. Підтримують zip, rar, 7z.

Вбудований провідник (zip), WinRAR, 7-Zip, WinZip, Bandizip.

 #### 6. 

Створення резервних копій (tar -czvf backup-$(date +%F).tar.gz /home), передача архівів по мережі, зменшення обсягу сховища.

Також використовується для логів, дистрибуції програм, створення snapshot-ів.
#### 7. 
Спеціальний пристрій-«чорна діра». Все, що туди записується, зникає. Використовується для приховування виводу або помилок (cmd > /dev/null 2>&1).
